# inzone-h9-gen1-headset-status

[English](README.md)

## 概要

Sony INZONE H9 / H7 ワイヤレスヘッドセット（初代）の状態を Windows のタスクトレイに表示するユーティリティです。

H9 / H7 ヘッドセットは専用のワイヤレスレシーバー経由で PC と接続しますが、
そのヘッドセットの電源状態の確認には公式のコンパニオンアプリ「INZONE Hub」を開く必要があります。

このユーティリティはコンパニオンアプリを開かずに、簡単にトレイアイコンから電源状態を確認できるようにします。

## 対応していないモデル

INZONE H9 II には非対応で、対応の予定もありません。H9 II のトランシーバーを挿しても検知されず、トレイの状態はドングルなしのままになります。

## 使い方

`--help` で使い方が出ます。

## インストール

[Releases](https://github.com/ugai/inzone-h9-gen1-headset-status/releases) から exe をダウンロードして、好きな場所に置いてください。インストーラー（`-setup.exe`）も用意しています。ユーザー単位でインストールし、更新しても自動起動の設定が維持されます。

ダウンロードした exe については、下記のコマンドでハッシュを確認できます。

```powershell
Get-FileHash .\inzone-h9-gen1-headset-status-*.exe -Algorithm SHA256
```

リリースに添付している同名の `.sha256` ファイルの値と一致すれば、ダウンロードは壊れていません。exe とインストーラーのどちらにも付いています。

これで分かるのはファイルが欠けていないことだけで、どこから来たかは分かりません。そちらはリリースに添付しているビルド証明で確認でき、[GitHub CLI](https://cli.github.com/) がビルドしたワークフローと照合します。

```powershell
gh attestation verify .\inzone-h9-gen1-headset-status-<version>.exe -R ugai/inzone-h9-gen1-headset-status
```

exe には署名を付けていないので、初回の起動で「Windows によって PC が保護されました」という警告が出ます。実行する場合は「詳細情報」をクリックして「実行」を押してください。

## ビルド

自分でビルドする場合は、Rust の開発ツールをインストールしてビルドコマンドを実行してください。

```bash
cargo build --release
```

## INZONE Hub との競合

このユーティリティと INZONE Hub が同時に起動していると、電源状態の取得で競合が発生します。
ヘッドセットの状態取得に必要な USB ドングル との通信が排他的な仕様になっているためです。

したがって、Hub が起動しているとこのユーティリティは状態をうまく取得できません。
逆にこのユーティリティ側はできるだけ Hub の起動を妨げないように状態を取得します。

> [!NOTE]
> 基本的な設定（オーディオイコライザーなど）は Hub を起動しなくても保持されているようです。
> 設定変更や特殊な機能を有効にしない限り Hub の常時起動は不要と思われます。

## パフォーマンス

単一バイナリ、ファイルサイズは約 300 KiB、常駐メモリは 数 MB 程度に抑えています。

> [!NOTE]
> ファイルサイズは CI で `.github/check-size.ps1` スクリプトを使ってチェックしています。

## 通信処理

外部ネットワークには接続せず、利用状況の送信も更新の自動確認も行いません。
状態の読み取りはレシーバーとの USB 接続だけで完結しています。

## 対応言語

日本語、英語に対応しています。Windows の言語設定に従います。設定ファイルで指定することもできます。
エラーメッセージの一部は英語のまま `INZONE: エラー（no reply）` のように出ることもあります。

## 表示スケーリング

トレイアイコンの描画は Windows の要求サイズを確認し、表示スケールに応じてサイズを切り替えます（150% なら 24px、200% なら 32px など）。起動中にスケールを変えた場合も追従を試みます。モニターの DPI スケーリングを元にサイズを決めています。

## 通知

システム通知は次の 2 種類です。

| 通知 | タイミング |
|---|---|
| ヘッドセットのオン/オフ通知 | ヘッドセットの電源がオン、オフに変わったとき、ペアリングを開始した時 |
| バッテリー残量低下の通知 | 残量が 35% 以下、15% 以下になったとき |

どちらも右クリックメニューから個別にオン/オフを切り替えられます。

バッテリー残量の通知は、しきい値以下になったタイミングで一度だけ通知されます。その後はある程度残量が回復してからでないと再通知されません。

オン/オフの通知は、電源状態を読めなかった期間をまたぐと出ません。INZONE Hub の起動中にヘッドセットの電源を切った場合、Hub を閉じてもオフの通知は出ずに、アイコンだけが灰色に変わります。

バッテリー残量の通知は今の残量を知らせるものなので、読めなかった期間をまたいでも出ます。ただし、起動して初めて読めた残量については、すでにしきい値以下でも通知しません。

> [!NOTE]
> システム通知の動作は次のコマンドで確認できます。
> 
> ```bash
> cargo run --release -- --test-toast
> ```

## 設定の保存先

### 通知設定

右クリックメニューの通知のオン/オフ設定は次のファイルに保存されます。

```
%APPDATA%\inzone-h9-gen1-headset-status\settings.conf
```

中身は `key=value` の平文で、ファイルを消すと次の既定値が使われます。

```
notify_power=on
notify_battery=on
language=auto
```

`language` には `auto` と `ja` と `en` のいずれかを指定できます。
`auto` は Windows の表示言語に従い、日本語環境以外は英語になります。
値を変えたときは、次回の起動から反映されます。

### 自動起動設定

右クリックメニューの設定からログオン時の自動起動のオン/オフを切り替えられます。
次のレジストリに登録され、Windows の設定のアプリやスタートアップの一覧にも出てくるはずです。

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
  inzone-h9-gen1-headset-status = "<exe のフルパス>"
```

## ポーリングの間隔

15 秒ごとに電源状態を取得します。

レシーバーが見つからない状態やエラーが続くと、30 秒、60 秒、120 秒とポーリングの間隔を延ばしていきます。INZONE Hub が使用中の間は 15 秒のままなので、Hub を閉じるとすぐに表示が戻ります。

ただし、レシーバーが挿し直されたときは即座に取得し直し、ポーリング間隔を元の 15 秒に戻します。
Windows のシリアルポートの増減の通知を見ているため、スリープ復帰時も同じように読み直されるはずです。

スリープからの復帰直後は数秒だけ灰色の円（電源オフ）表示が続きますが、ヘッドセット側が再接続を試みているためなので、
何秒か待つと再接続されて、通常の状態（電源オンなら緑）に戻ります。

## その他の挙動

- 二重起動を防止するため、すでに起動している状態でもう一度起動するとメッセージを出して終了します
- 右クリックメニューの「更新を確認」は、リリースページを既定のブラウザで開きます

## 検証環境

現バージョンでは、INZONE H9 (初代) と特定のドングル（`054C:0E53`）、Windows 11 (25H2) の組み合わせで動作を検証しています。

他の環境での動作は未確認です。

次の機能は実装してありますが、条件を用意できておらず、実機では確認できていません。

- INZONE H7 での動作
- 日本語以外の Windows での言語の自動判定（`settings.conf` の `language=en` による表示は確認済みです）
- ペアリング中の表示（青い円と、中空のバッジ）
- バッテリーが減ったときの表示と通知（黄、赤、低下の通知）の正確さ

ドングルやヘッドセットのファームウェアが更新されると、応答の形式が変わって状態を読めなくなる可能性があります。

## 既知の制限

動作を確認の上、意図して受け入れているものです。

- INZONE Hub が起動する瞬間にこちらがポートを握っていると、Hub 側がポートを取れないことがある（通常は 15 秒に一度、数百ミリ秒です。ヘッドセットが応答しないときは最大 8 秒ほど握ります）
- モニターごとに表示スケールが違い、なおかつタスクバーがセカンダリモニター側にある場合、アイコンのサイズが合わない
- Windows の設定でスタートアップをオフにしても、右クリックメニューのチェックには反映されず、チェックがついたままになる
